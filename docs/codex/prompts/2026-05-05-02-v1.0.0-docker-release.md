## 已知限制

- GHCR package 在维护者设置为 Public 前，匿名 `docker pull` 会返回 `unauthorized`。
- 本轮曾临时推送过 `ghcr.io/wodenwang/bpmt-oauth-demo:1.0.0`，后续正式文档和 Compose 均只使用 `v1.0.0`；删除旧 tag 需要 `delete:packages` 权限，本轮未处理。
- Docker Compose 文件中包含密钥占位符，部署者必须在本机副本中替换后再运行。
- 完整 OAuth 登录链路需要真实 BPMT 环境和数据库状态，本轮以自动化测试、Compose 校验和镜像发布为主要 release gate。
