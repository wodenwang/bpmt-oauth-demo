# bpmt-oauth-demo v1.0.0

## 发布目标

`v1.0.0` 是 `bpmt-lite` OAuth 第三方登录 demo 的第一个正式版本，交付可通过 Docker Compose 运行的示例应用。

## 镜像

- `ghcr.io/wodenwang/bpmt-oauth-demo:v1.0.0`
- `ghcr.io/wodenwang/bpmt-oauth-demo:latest`

GHCR package visibility 由维护者在 GitHub Packages 页面设置为 Public。设置完成后，以上镜像可未登录拉取。

镜像按多架构发布，覆盖：

- `linux/amd64`，适用于常见 x86_64 Linux 主机。
- `linux/arm64`，适用于 Apple Silicon、ARM 服务器和 ARM Linux 主机。

## 运行方式

先编辑 `docker-compose.yml`，替换 `<DEMO_SESSION_SECRET>`、`<BPMT_OAUTH_CLIENT_SECRET>`、`<BPMT_API_APP_SECRET>`、`<DB_USER>` 和 `<DB_PASSWORD>`。

初始化动态表：

```bash
docker compose run --rm setup
```

启动 demo：

```bash
docker compose up -d app
```

访问地址：

```text
http://localhost:81
```

## 交付范围

- OAuth2 Authorization Code 登录入口、回调、token 换取和 userinfo 读取。
- demo 本地 session。
- BPMT `DEMO_MESSAGE` 动态表初始化。
- 留言登记的查询、新增、查看、编辑、删除和批量删除。
- Dockerfile 镜像构建。
- `docker-compose.yml` 部署入口，宿主机端口映射为 `81:81`，容器内部端口使用镜像默认值。
- GHCR 多架构镜像，支持 `linux/amd64` 和 `linux/arm64`。

## 不包含

- OIDC、`id_token`、refresh token。
- 跨系统单点登出。
- BPMT 或 MariaDB 容器编排；本 demo 对接已有 BPMT 和 MariaDB。

## 已知限制

- 运行前必须在 BPMT 后台登记 `client_id=bpmt-oauth-demo`，回调地址必须精确为 `http://localhost:81/oauth/callback`。
- 真实 `client_secret`、`BPMT_API_APP_SECRET` 和数据库密码不得提交到 Git。
