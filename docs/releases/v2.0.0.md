# bpmt-oauth-demo v2.0.0

## 发布目标

`v2.0.0` 是移动端 H5 体验版本，把 demo 主界面从桌面表格重构为手机优先的信息流页面。

## 主要变化

- 首页改为留言卡片信息流。
- 新增留言、查看详情和编辑留言改为独立页面。
- 手机浏览器和 BPMT 内嵌 H5/iframe 场景下，页面宽度、滚动、返回和表单交互更稳定。
- PC 浏览器使用同一套页面，以宽屏卡片布局兼容。

## 保持不变

- OAuth2 Authorization Code 登录流程不变。
- `client_id` 和回调地址精确匹配规则不变。
- Docker Compose 运行方式和环境变量语义不变。
- demo 仍使用服务端 session，不把 BPMT `access_token` 当作永久会话。

## 不包含

- OIDC、`id_token`、refresh token。
- 跨系统单点登出。
- 独立前端 SPA 构建链。

## 验证范围

- `npm test`
- 手机 viewport 浏览器验证：登录、首页卡片、搜索、新增、查看、编辑、删除、退出。
- PC 宽屏浏览器验证：页面可读、控件不重叠。
- 敏感信息扫描。

## 已知限制

- 批量删除不再作为移动端主流程展示。
- 本 demo 仍依赖已运行的 BPMT 和 MariaDB 环境。
