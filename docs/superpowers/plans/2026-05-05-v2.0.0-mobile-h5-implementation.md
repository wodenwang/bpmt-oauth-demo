# bpmt-oauth-demo v2.0.0 Mobile H5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the v2.0.0 mobile-first H5 experience for `bpmt-oauth-demo`: card-based message feed, standalone create/detail/edit pages, and responsive PC compatibility without changing OAuth behavior.

**Architecture:** Keep the existing Express/EJS server-rendered architecture. Reuse OAuth/session/message service boundaries, add page routes in `src/messages/routes.js`, replace the table/modal UI with mobile-first EJS templates and CSS, and keep JavaScript limited to progressive interactions such as delete confirmation and filter toggling.

**Tech Stack:** Node.js 20, Express 4, EJS, express-session, mysql2, native browser JavaScript, Node test runner, supertest.

```js
router.get('/messages/:id', requireLogin, async (req, res, next) => {
  try {
    const message = await service.findById(req.params.id);
    if (!message) {
      throw notFound();
    }
    const user = currentUser(req);
    res.render('messages/detail', {
      title: message.title || '查看留言',
      user,
      message,
      owned: isOwner(message, user),
      backHref: '/'
    });
  } catch (error) {
    next(error);
  }
});

router.get('/messages/:id/edit', requireLogin, async (req, res, next) => {
  try {
    const message = await service.findById(req.params.id);
    if (!message) {
      throw notFound();

    res.render('messages/form', {
      title: '编辑留言',
      user: currentUser(req),
      mode: 'edit',
      message,
      action: `/messages/${encodeURIComponent(req.params.id)}/update`,
      backHref: `/messages/${encodeURIComponent(req.params.id)}`
```

```js
function confirmDelete(event) {
  if (!window.confirm('确认删除这条留言？')) {
    event.preventDefault();
  }
}

function toggleFilterPanel() {
  const panel = document.querySelector('[data-filter-panel]');
  if (!panel) {
    return;
  }
  panel.toggleAttribute('data-open');
}

document.querySelectorAll('[data-confirm-delete]').forEach((form) => {
  form.addEventListener('submit', confirmDelete);
});

document.querySelectorAll('[data-toggle-filter]').forEach((button) => {
  button.addEventListener('click', toggleFilterPanel);
});
```
